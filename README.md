# Corpus Linguistics - Study 1 - Katherine

## Phase 1 - Lexical Multi-Dimensional Analysis (LMDA) prompt engineering for interpretation

This project supports a study comparing how human-authored and LLM-generated interpretations of Lexical Multi-Dimensional Analysis (LMDA) differ.

Phase 1 focuses on engineering the interpretation prompt to be presented to both human analysts and large language models. The study is based on a corpus of fashion discourse that produced five lexical dimensions, each represented by a positive pole.

The purpose of this phase is to prepare a standardised interpretation task containing the information required for analysts, whether human or AI-based, to interpret each LMDA dimension pole. The prompt materials are designed to support consistent comparison between human interpretations and outputs generated by different LLMs.

Input information, obtained from the researcher, was stored and processed in `docs/interpretation`.

The input documents were processed to obtain the following information for each dimension pole:

- Mean factor scores of the registers in the pole;
- Lexical loadings in the pole;
- High-scoring example excerpts in the pole.

Prompt document templates, in Markdown format, were created based on references from related projects and stored in:

- `cl_st1_ph1_katherine/interpretations_prompt_templates`

One prompt document per dimension pole was then created using the corresponding input information. These prompt documents were stored in both Markdown and DOCX formats in:

- `cl_st1_ph1_katherine/interpretation_prompts`

The resulting set of prompt documents was preliminarily tested with JetBrains AI Assistant LLM (https://www.jetbrains.com/ai/). For each test, the relevant prompt document was attached to a chat window together with the command:
```plain text
Please complete the task as specified.
```
The testing outputs were stored in both Markdown and DOCX formats in:

- `cl_st1_ph1_katherine/llm_testing`

The next steps involve reviewing the preliminary LLM testing outputs, making any necessary adjustments to the prompt documents, releasing the refined interpretation task to human researchers, and processing the final prompt documents with multiple AI models for comparison.
